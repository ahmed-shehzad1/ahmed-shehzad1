## 🏛️ How I Structure Backend Systems

```text
                         ┌─────────────────────┐
                         │      Client         │
                         │ Next.js / REST API  │
                         └──────────┬──────────┘
                                    │
                                    ▼
                         ┌─────────────────────┐
                         │     Middleware      │
                         │ JWT · OAuth · RBAC  │
                         └──────────┬──────────┘
                                    │
                                    ▼
                         ┌─────────────────────┐
                         │     Controller      │
                         │ Validation · DTOs   │
                         └──────────┬──────────┘
                                    │
                                    ▼
                         ┌─────────────────────┐
                         │      Service       │
                         │ Business Logic     │
                         └───────┬─────┬───────┘
                                 │     │
                     ┌───────────┘     └────────────┐
                     ▼                              ▼
          ┌────────────────────┐          ┌──────────────────┐
          │ Deterministic      │          │     AI Router    │
          │ Processing Engine   │          │ Gemini / Groq    │
          └──────────┬─────────┘          │ OpenAI / Claude  │
                     │                    └────────┬─────────┘
                     └──────────────┬─────────────┘
                                    ▼
                         ┌─────────────────────┐
                         │     Repository      │
                         │    Data Access      │
                         └──────────┬──────────┘
                                    │
                                    ▼
                         ┌─────────────────────┐
                         │ PostgreSQL + Prisma │
                         │ Transactions · ORM  │
                         └─────────────────────┘
```
