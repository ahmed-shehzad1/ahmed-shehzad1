### 🚀 Featured Engineering Projects

#### 🎓 AIRO — Academic Intelligence & Resource Orchestrator
> **Enterprise Monorepo Platform for Academic Knowledge Management, Google Classroom Sync & Multi-AI Processing**

- **Overview:** An end-to-end academic platform connecting Students, Teachers, and Admins. It syncs Google Classroom materials, runs deterministic rule classification before routing to AI fallbacks, and manages curated academic resource repositories.
- **Architectural Highlights:**
  - Built as a Turborepo monorepo with strict layer isolation (Routes → Controllers → Services → Repositories).
  - PostgreSQL schema managed via Prisma ORM with relational constraints and transactional workflows.
  - Deterministic classification engine for course aliases and metadata, paired with a provider-agnostic AI Router (Gemini, Groq, OpenAI, Claude).
  - Multi-tier document publishing workflow (`PRIVATE` → `PENDING_REVIEW` → `PUBLISHED`).
- **Tech Stack:** Next.js, React, Node.js, Express, TypeScript, PostgreSQL, Prisma ORM, Turborepo, Google Classroom API, OAuth 2.0, Multi-AI Adapters
