### 🏛️ Backend Architecture Pattern

```
[ Client Request ]   ─────────  Next.js · REST API
        │
[ Middleware ]       ─────────  JWT · OAuth 2.0 · RBAC validation
        │
[ Controller ]       ─────────  DTO input validation & sanitization
        │
[ Service ]          ─────────  Business logic · deterministic engine
        │         └──           AI Router fallback (Gemini / Groq / OpenAI / Claude)
[ Repository ]       ─────────  Data access abstraction
        │
[ Database ]         ─────────  PostgreSQL · Prisma ORM (transaction-safe)
```
